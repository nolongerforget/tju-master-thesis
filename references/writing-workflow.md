# 写作与引用工作流

以下为本技能的执行建议。涉及校方硬性要求时以 [格式规范](format-rules.md) 和源文件为准；章节数量、写作顺序及材料组织办法不是学校规定。

## 提纲和正文

从研究问题、已完成工作、可用证据和结论出发组织章节。让每一章具有明确问题、方法或分析、结果、解释，并与总研究问题相连。不要用通用六章框架取代学科实际需要。

工科实验或计算研究可以参考“绪论—理论或方法基础—研究方法—实验/仿真与结果—讨论—结论与展望”，也可按多项研究分别成章。人文、管理、设计及其他学科应根据其论证、案例、调查或作品结构调整。小结是否单列、具体章数和字数分配由研究需要决定。

设计提纲时，写出各节拟回答的问题、可用材料、缺失材料、拟用图表及与其他章节的关系。只在用户需要时估算字数；三万字的一般要求不能转化为堆砌背景、重复讨论或编造结果的理由。

| 部分 | 写作要点与证据 |
| --- | --- |
| 绪论 | 界定研究对象、问题及边界；综述真实相关研究并比较方法、结果与局限；由文献和实际问题导出研究目标 |
| 理论或方法基础 | 仅解释后文实际使用的概念、理论与符号；说明适用条件，与自有研究贡献区分 |
| 方法 | 依据已提供事实描述数据来源、样本、材料、装置、变量、步骤、参数及分析方法，信息足以支持理解和复核 |
| 结果 | 围绕问题呈现实测、计算、调查或分析结果；数据与图表一致，区分观测与解释 |
| 讨论 | 与已有研究比较，说明可能机制、适用边界、局限与不确定性；不把相关性直接写成因果 |
| 结论与展望 | 回答研究问题，说明已证实贡献和限制；未开展工作写成展望，不写成成果 |

资料不足时，可先交付结构化草稿并标明 `【待补】`，但不能将占位内容混入可提交终稿。用户只要求一个章节或一个段落时，按该范围完成。

## 润色和翻译

- 保留数据、单位、限定条件、术语、引用关系和结论强度；不为语言顺畅而改变技术含义。
- 消除歧义和重复，补足必要的逻辑衔接；技术冲突应指出并依据材料处理，不能默默改成猜测。
- 长篇修改维持术语表、符号表、章节交叉引用与缩写首次定义一致。目录与章名同步。
- 摘要英文翻译逐项对照目的、方法、结果、结论、数值及关键词，避免在英文中增添中文没有的贡献。
- 用户只要润色文本时直接提供文本；重大事实冲突和待补材料另作简短说明。

## 摘要

从已得到支持的研究结果写摘要，依次覆盖研究目的、主要方法、关键结果和结论，明确贡献。结果量化仅使用已提供或已核验数据，不为“增强说服力”补造百分比、显著性或对比结论。

中文摘要一般300—600字，特殊需要可略多，原则上不超过一页。摘要应独立、自含，不加注释；关键词3—8个，单独成段。按格式规范设置标签、字号与逗号分隔。英文摘要内容对应中文，标题使用“ABSTRACT”，关键词标签使用“KEY WORDS:”，每个关键词首字母大写。

只有摘要文本时可检查字数、关键词数、事实和中英一致性；一页要求须在实际排版后验证。

## 文献和引用

原文依据：正文“参考文献”P081—P082、P140—P184；P编号定义见格式规范。

1. 先检查用户已有的引用体系和文献库。原文允许顺序编码制或著者—出版年制，全文必须统一；不要擅自将已有合规体系改成另一种。
2. 新稿尚无体系且用户未指定时，可默认顺序编码制，并明确这是工作选择。正文引用按原文要求使用上标。对于著者—出版年制与上标引用的具体组合，原文件未给出完整示范，需核对适用学院模板，不能声称只有一种写法。
3. 每条文献核对作者、题名、出处、年份、卷期、页码或文章号等实际适用字段。需外部核验时检索出版方、期刊、机构库等可靠来源；未经核验的条目、链接或DOI不得伪装为已确认。
4. 仅将作者直接阅读且在正文引用的资料纳入最终参考文献。不把搜索结果、他文转引、模型记忆、用户未经确认的文献表等同于作者已阅读原文。
5. 引文和文后条目双向核对，删除重复或孤立条目应先核实上下文；缺信息标为待补，不编造。待核验候选文献可单列给用户，不混入正式编号。

原文指定GB/T 7714—2005，并提及其他类型可参照GB 7713-87末尾示例。本技能不自动升级标准年份。用户另行要求某一版本时照要求执行，并标明与本源文件不同；需要解释该外部标准具体细则时先核验相应标准内容。

### 作者和标点

- 原文P144表述为“3人以下全部著录，3人以上可只著录前3人”，端点措辞不严谨。可操作口径为三名作者时列全，超过三名可列前三名加“等”或“et al”；这是对该表述的明确化。`et al`无需斜体。
- 责任者之间用逗号，姓名姓前名后。
- 中文文献按原文示例使用全角分隔标点，后续内容紧排；英文使用半角标点，后空一格。原文P147输入法措辞含混，不改写成新的强制键盘输入规则；人工或工具排版以实际字符和一致性核对。
- 出版地指出版公司所在地，不是印刷地。

### 常用著录结构

以下来自原文示例结构，方括号内的类型标志保留。这里只示意字段顺序，不能将占位字段当成真实文献。

| 类型 | 原文结构 |
| --- | --- |
| 图书 | 作者．书名[M]．出版地：出版者，出版年：起止页码． |
| 期刊 | 作者．文题[J]．刊名：其他题名信息，年，卷(期号)：起止页码．获取和访问路径． |
| 论文集、会议录 | 作者．文题[C]．文集名，出版地：出版者，出版年：起止页码． |
| 学位论文 | 作者．文题[D]．授予地：授予单位，授予年． |
| 专利 | 申请者．专利名：专利国别，专利号[P]．授权日期[引用日期]． |
| 电子文献 | 作者．题名[文献类型/载体类型]．出版地：出版者，出版年（更新或修改日期）[引用日期]．获取和访问路径． |

字段是否适用取决于文献实际类型；不机械填充不存在的信息。原文示例不足以解决某种著录情形时，回查相应版本的标准或已确认模板，不从示例推断全部规则。

原文文献类型代码：M图书、C论文集/会议录、G汇编、N报纸、J期刊、D学位论文、R报告、S标准、P专利、DB数据库、CP计算机程序、EB电子公告。电子载体代码：MT磁带、DK磁盘、CD光盘、OL联机网络。纸本文献不需加载体类型。

## 分阶段协作

长篇论文按用户需要逐章推进，维护研究事实、术语和引用的连续性。阶段末集中核对题目与研究目标、摘要与结果、图表与正文、结论与证据的一致性。不能因为全文未完成，就阻止当前章节的有效写作；也不能把局部写作成果称为已通过整篇论文审查。
