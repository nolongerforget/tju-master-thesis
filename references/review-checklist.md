# 硕士论文检查清单

在审稿、排版验证或交付前使用。检查范围随用户任务确定：单章润色不必补齐封面材料；完成全文时覆盖结构、内容、格式、引用和交付版本。参数和出处见 [format-rules.md](format-rules.md)、[source-and-title-pages.md](source-and-title-pages.md)；写作组织见 [writing-workflow.md](writing-workflow.md)。

## 状态与证据

每个结论给出可定位证据，例如章节标题、可检索原句、段落、图表号或实际渲染页码。页码必须来自所查版本，不把提取序号当页码。

使用以下状态：

- **通过**：在本次材料和检查范围内已有支持证据。
- **不符合**：实际内容或格式与明确适用条款不一致。
- **待确认**：缺少必要信息、规则存在歧义或版本适用性未明确。
- **未检查**：当前未执行检查，或输入格式、工具能力不足以检查。
- **不适用**：本次交付确实不涉及该项，并简述原因。

不要把“未发现”写成“已全部符合”。文字提取可以检查标题和文本，不能证明真实字体、页边距、分页、奇偶页、图表溢出及签名状态；只有 Markdown 或聊天文本时，这些排版项标为未检查。Word XML 中的属性也不能代替实际分页的视觉验证。

## 按任务选择检查项

### 题目、提纲和章节写作

- [ ] 题目覆盖真实研究内容，长度按原文25字以内要求检查；必要副标题不用于掩盖超长主标题。
- [ ] 提纲围绕研究问题、已有研究、方法、证据与结论组织；章数及篇幅安排标明为写作建议。
- [ ] 国内外研究现状、理论/计算/实验方法、结果分析、结论及意义等按研究类型得到适当呈现，未为凑齐标题添加无关实验或内容。
- [ ] 论证中区分已有研究、作者工作、观察结果和解释；没有将相关性写成已证明因果关系。
- [ ] 方法、数据、实验条件、对照、误差及结论有资料支持；缺失数据、数值或引用明确待补，不虚构结果或创新。
- [ ] 术语、缩写、符号、单位及图表名称前后一致；首次出现的专门符号得到说明。
- [ ] 润色保持原意、证据强度和用户指定范围；需要改变科学结论的地方单独提出。

### 中英文摘要

- [ ] 中文摘要含目的、方法、结果、结论及有依据的创新点，独立自含，不加注释。
- [ ] 一般300–600字；特殊超出须有合理任务背景并报告，原则上控制一页。
- [ ] 关键词3–8个，与正文领域和核心内容一致；中英文关键词逐项对应。
- [ ] 英文摘要忠实对应中文结果、数字、限定条件和结论，没有额外扩张。
- [ ] 在可排版文件中核查标题、关键词标签字号与粗体、字体、间隔一行、无缩进、逗号分隔及英文大小写。

### 全文结构与扉页

- [ ] 按规定十一部分顺序检查；未提供的部分记录为缺失或待确认，不用虚构内容填充。
- [ ] 选择学术硕士附件4或专业硕士附件5；实践成果总结报告另按附件6处理。
- [ ] 封面、扉页、学籍资料中的对应信息一致；学科/专业、导师、企业导师、委员等有真实依据。
- [ ] 新题名页不超过一页，委员行数对应实际人数，说明性备注已清除。
- [ ] 新扉页英文题目位置已得到依据；若未解决，准确标为待确认，不宣称扉页完全合规。
- [ ] 声明与授权文本使用附录C，保留相应签名与日期位置；按电子版或签署归档版判断签名要求。
- [ ] 目录到三级，含正文及其后各部分，条目与标题一致，实际页码已更新。
- [ ] 硕士篇幅与“一般不少于3万字”要求核对；报告统计范围与方法，不推定学校未写明的口径。
- [ ] 成果说明的论文、项目、本人角色与材料一致；致谢限一页。

### 引用、图表与公式

- [ ] 参考文献确为作者直接阅读且正文引用过；仅有搜索结果或题录的材料不能被标记为作者已阅读。
- [ ] 正文引用和文末条目相互对应，无缺项、孤立条目或顺序错位；著录信息有可靠依据。
- [ ] 按本版规定采用 GB/T 7714—2005，顺序编码制或著者—出版年制全文统一，上标引用符合条款。
- [ ] 作者、题名、年份、卷期、页码、链接等未凭空补齐；作者截断、姓名顺序和中英文标点一致。
- [ ] 图表自名性、必要性和数据来源清楚，量与单位齐全，术语与正文一致。
- [ ] 图下题、表上题居中；按章编号；引用图表在题右上角标来源，附注在图表下方。
- [ ] 跨页表格重复表序和表头，标“（续）”；表题是否重复按原文可选规则处理。
- [ ] 公式仅行间编号、编号右对齐并用英文小括号；变量参数使用数学格式，必要含义已说明。
- [ ] 脚注与参考文献用途分明，脚注按章标号；附录编号与正文分开并含附录序码。
- [ ] 三线表属于建议；不能单凭未用三线表判定违反硬性条款。

### Word 或其他实际排版文件

- [ ] A4尺寸、四边页边距、页眉和页脚距边界按参数表逐项核查。
- [ ] 正文中西文字体、小四、固定20磅、段前后0、首行2字符已核查；数学行距例外有实际需要。
- [ ] 各级标题字体、字号、对齐、编号及段前后间距在相应区间；目录缩进和前导符正确。
- [ ] 图表内容、脚注、参考文献分别采用规定字号或行距，未被统一正文样式覆盖。
- [ ] 中文摘要起用大写罗马页码；正文重新从阿拉伯1开始并延续至末尾。
- [ ] 页眉从正文至末尾，奇数页对应章标题、偶数页“天津大学硕士学位论文”，字号与居中正确。
- [ ] 双面布局下每章从右页/奇数页开始；检查实际页序和自动空白页，不只检查是否存在分页符。
- [ ] 实际渲染已检查字体缺失/替代、目录页码、标题孤行、图表溢出、公式裁切、页眉页脚及分页；发现缺陷后修正并核对受影响区域。
- [ ] 无法取得渲染时说明限制，不能只凭文本或样式属性宣布版式全部通过。

### 提交版本

- [ ] 印刷版与提交电子版内容和格式一致；电子版允许省略封面、手写签名的例外已按交付场景处理。
- [ ] 实际缺失材料、未解决的规范冲突和未检查项目在交付说明中可见；不把待补信息隐藏成最终结论。
- [ ] 仅在用户明确要求盲审/匿名稿时核对相应脱敏范围，以学院规则为准；不自动删除正式归档稿应有的姓名和声明。
- [ ] 交付的是用户请求的范围和文件格式；审稿批注、待办说明与可提交正文清楚区分。

## 问题报告模板

报告先说明当前最重要的问题及检查范围，再给具体问题。仅列实际发现和重要待确认项，避免复制整张未执行清单。

```text
检查对象：文件或章节名称、版本
检查范围：内容 / 引用 / 结构 / 文件属性 / 实际渲染
结论：已通过哪些检查，哪些项目仍不符合、待确认或未检查

| 位置 | 状态 | 发现及证据 | 依据 | 建议修订或下一步 |
| ... | 不符合 / 待确认 / 未检查 | 可检索原句或实际属性 | 原文小节或明确标记的写作建议 | 可执行修改 |

已修订：简述实际完成的修改。
待用户补充：仅列影响后续完成的材料或选择。
检查限制：如未取得完整文献、未渲染、仅收到单章等。
```

问题的“依据”须区分学校明确要求、学校建议、用户/学院补充要求、本技能写作建议和源文件歧义。报告修改建议时，不将新增的个人偏好包装为学校规定。
