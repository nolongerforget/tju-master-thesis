# 天津大学硕士论文格式规范

本表转述用户所给文件正文的明确要求。定位使用原文章节名称；P编号是原始DOCX中正文顶层段落或表格依次计数的位置（包括空段落），不代表页码。字体磅值是常用中文字号的排版换算，属于实现参数，并非原文另增要求。

## 结构与内容

来源：“论文的结构”“论文各部分的形式与内容”，P043—P093。

顺序为：封面 → 扉页 → 独创性声明、学位论文使用授权说明 → 中文摘要 → 英文摘要 → 目录 → 正文 → 参考文献 → 附录 → 发表论文和参加科研情况说明 → 致谢。

| 项目 | 规定 |
| --- | --- |
| 封面 | 使用学校统一印制、与所授学位种类相符的封面；字段与扉页一致 |
| 题目 | 严格控制在25字以内，必要时可加副标题；尽量避免符号、简称、缩写和商品名。原文未细分副标题的计数口径 |
| 学科或专业名称 | 按适用的正式学科、专业目录与培养信息填写；使用用户提供或已核验的正式名称，不猜测 |
| 中文摘要 | 独立、自含，不加注释；说明目的、方法、结果、结论，明确创新点；一般300—600字，特殊需要可略多，原则上不超过一页 |
| 中文关键词 | 3—8个，另起一段；尽量采用专业规范主题词 |
| 英文摘要和关键词 | 与中文摘要及关键词内容一致 |
| 目录 | 列至三级标题，包含正文及其后各部分，附对应页码；条目文字与实际标题完全一致 |
| 正文 | 硕士学位论文一般不少于三万字；除外语类相关专业外，正文使用中文简体字及规范中文标点；量与单位优先采用国际及国家标准推荐的新名称，一般使用国际单位制 |
| 正文内容 | 一般包括国内外研究现状、理论分析、计算方法、实验装置和测试方法、结果分析与讨论、研究结果、结论及意义等，依研究适用性组织 |
| 附录 | 可放冗长推导、辅助数学工具、符号和缩写说明、计算程序及说明等 |
| 发表论文和参加科研情况说明 | 简明列明在学期间的论文、项目、科研工作及承担任务或角色，仅填写真实信息 |
| 致谢 | 限一页，感谢实际资助、协助、建议、授权或支持者 |

无附录、无已发表论文或无相关项目时，先根据真实情况和适用要求处理栏目，不为凑齐结构编造内容。

## 页面、打印与页码

来源：“论文印刷装订格式”P095—P102；“页眉、页脚”P195—P197。

| 参数 | 原文规定 |
| --- | --- |
| 纸型 | A4，210 × 297 mm |
| 上、下页边距 | 上27.5 mm，下25.4 mm |
| 左、右页边距 | 左35.7 mm，右27.7 mm |
| 页眉、页脚距边界 | 页眉15.0 mm，页脚17.5 mm |
| 打印 | 双面；每一章从另页右页，即奇数页开始 |
| 页眉范围 | 正文开始至论文结尾 |
| 奇数页页眉 | 相应章标题或不编号章标题 |
| 偶数页页眉 | 天津大学硕士学位论文 |
| 页眉样式 | 五号（10.5 pt），居中，其余同正文 |
| 前置部分页码 | 中文摘要开始，从 I 起使用大写罗马数字顺序编号 |
| 正文及后置部分页码 | 正文第一页重置为阿拉伯数字1，连续到论文结尾 |
| 页脚样式 | 小五号（9 pt），居中 |
| 印刷内容 | 印刷版与提交电子版内容和格式严格一致；电子版可不含封面、手写签名 |
| 装订 | 建议胶装；裁剪后纸张大小建议符合ISO 216公差 |

实现时不要擅自增加装订线、镜像页边距或页眉横线。原文未明确这些设置。用分节和奇数页起章控制分页；插入空白页后仍须检查页码与物理右页是否一致。实践成果总结报告的页眉文字原文未单独规定，确认适用要求后处理，不直接把论文名称替换成未经确认的规范。

## 字体与段落

来源：“论文内容排版格式”P105—P129。

| 对象 | 字体与字号 | 对齐和间距 |
| --- | --- | --- |
| 正文中文 | 宋体，小四（12 pt） | 固定20 pt行距；段前、段后0；首行缩进2字符 |
| 正文西文 | Times New Roman，小四（12 pt） | 同正文；缺少相应字符时选清晰通用的字体 |
| 中文论文题目 | 宋体，二号（22 pt），加粗 | 按正式扉页原样式 |
| 英文论文题目 | Times New Roman，二号（22 pt），加粗 | 按适用扉页安排，注意新版示例差异 |
| 摘要标题 | “摘要”，宋体二号，加粗 | 居中 |
| ABSTRACT | Times New Roman二号，加粗 | 居中，全大写 |
| 摘要内容 | 中文使用正文样式；英文全部Times New Roman | 正文样式 |
| 关键词标签 | “关键词：”宋体四号（14 pt）加粗；“KEY WORDS:” Times New Roman四号加粗 | 与摘要间隔一行，无缩进左对齐 |
| 关键词内容 | 正文样式，英文Times New Roman | 逗号分隔，换行不缩进；英文每个关键词的首字母大写 |
| 章标题 | 黑体小三（15 pt） | 居中，段前、段后各30—36 pt；“第1章 标题” |
| 不编号章标题 | 同章标题 | 无编号 |
| 二级标题 | 黑体四号（14 pt） | 左对齐无缩进，段前、段后各18—24 pt；“1.1 标题” |
| 三级标题 | 黑体四号（14 pt） | 左对齐无缩进，段前、段后各12—15 pt；“1.1.1 标题” |
| 四级标题 | 黑体小四（12 pt） | 左对齐无缩进，段前、段后各9—12 pt；“1.1.1.1 标题” |

各级标题编号与标题内容之间一个空格。正文允许四级标题，目录只列至三级。使用字号换算时设置中文字体与西文字体分别生效，避免主题字体或局部格式覆盖。

章标题等间距在规定范围内统一即可。若新建文件且未指定，可将章标题、二级、三级、四级段前段后分别取30、18、12、9 pt；这是实现默认值，不能据此将其他合规取值判为错误。原文未另定标题行距和图表题注的独立字号，不虚构唯一强制值。

## 目录与后置部分

- “目录”采用不编号章标题样式；条目采用正文样式，各级逐级缩进，每级增加2字符，页码前导符为“…”。
- “参考文献”采用不编号章标题样式；条目固定17 pt行距，段前3 pt、段后0，其余同正文。文献著录与引用规则见 [写作工作流](writing-workflow.md#文献和引用)。
- 附录按大写正体A、B、C编序号；标题采用不编号章标题样式、正文采用正文样式。附录图、表、式、文献独立编号，冠以附录序码。
- 原文附录编号示例混用“图A01”“表B-2”“式(B-3)”“文献[A5]”（P192）。不要把示例悄悄改成唯一校规；实际统一标点形式前核对学院模板，暂用方案应明确为实现选择。
- “发表论文和参加科研情况说明”“致谢”采用不编号章标题样式，正文采用正文样式。

## 图表、公式和脚注

来源：P077—P080、P130—P139。

| 项目 | 要求 |
| --- | --- |
| 内容 | 图表具有自名性；图精简，避免与表和文字重复；术语、符号、单位与正文一致 |
| 表格 | 参数标明量和单位符号；建议三线表 |
| 编号 | 图、表、公式使用阿拉伯数字分章编号；图表章号与序号用“-”连接，如图2-1、表2-1 |
| 图表间距 | 图、表等与前后正文之间有一行间距；用段落属性实现并核对视觉效果 |
| 图题 | 图序及图题居中放在图下方 |
| 表题 | 表序及表题居中放在表上方 |
| 续表 | 后续每页重复表序，接表题（可省略）及“（续）”，放表上方；重复表头 |
| 引用图表 | 图题或表题右上角标出文献来源 |
| 图表附注及子图 | 附注置下方，以英文小写字母顺序编号；子图以英文字母编号 |
| 图表内容字体 | 五号（10.5 pt）；中文宋体，英文Times New Roman |
| 公式 | 标准通用；非公认变量、参数应解释；变量、参数必须用数学格式或行内公式格式 |
| 公式编号 | 仅行间公式可编号，右对齐，英文小括号，无引导符；其余样式同正文。正文按章编号的括号示例可实现为“(2-1)”，连字符是实现选择 |
| 含行内公式段落 | 可用单倍行距，这是允许例外，不宜误判为固定20 pt违规 |
| 脚注 | 文内编号加脚注；阿拉伯数字上标，Times New Roman，分章节连续标号；脚注五号，其余同正文 |

脚注用于说明性注释。参考文献条目集中放文后参考文献部分，不放章节末尾或页面脚注。
